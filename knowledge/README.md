# 本地知识库数据（隐私，不入库）

`knowledge/` 目录存放**本机私有**的知识库数据，已通过 `.gitignore` 排除，**不会**被提交/推送到 git：

- `corpus/` — 原始文件（PDF、文本等），如检验报告
- `index/` — 分块索引 `index.json`（由知识库引擎维护）

## 其他电脑如何启用知识库

1. 克隆仓库后，把要入库的文件放进 `knowledge/corpus/`（或放到工作区任意位置）
2. 在 Web UI 知识库面板点「选择文件」/输入文件名入库，或调用 `knowledge_add` 工具
3. 引擎会自动分块、建索引，之后 `knowledge_search`、@引用、自动注入即可使用

空知识库不会报错——面板显示"知识库为空"引导，检索返回空结果。
