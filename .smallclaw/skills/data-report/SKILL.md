# 数据整理报告（Data Summary Report）

把表格 / CSV / 含数据材料整理成统计报表或结构化数据报告。适合"材料数据分析、整理、总结、提炼"场景。

## 何时使用

- 用户要求"整理 / 统计 / 汇总 / 透视 / 对比 / 清洗 数据/表格/CSV"
- 材料含多行数据，需要计算指标或提炼结论

## 执行流程（严格按序）

### 第 1 步 · 摸清结构
用 `doc_inspect` 查看文件类型、sheet 列表、行列数。不要猜列名。

### 第 2 步 · 读取数据
用 `doc_read` 读取数据（可带 range / limit 控制体积）。多 sheet 逐个读。

### 第 3 步 · 计算关键指标
- 合计 / 均值 / 占比 / 趋势 / 极值，逐项标注**口径**（怎么算的）
- 需要透视分组时用 `doc_pivot`（按分类汇总数值列）
- 需要公式时用 `doc_write` 的 xlsx formula op（如 =SUM(C2:C6)）

### 第 4 步 · 生成产物
- 数据量大或有报表需求 → `doc_write` 生成 .xlsx（透视/公式/格式化）
- 数据量小或结论导向 → 生成结构化数据报告（表格 + 结论）

### 第 5 步 · 交付
FINAL 说明：文件路径 + 关键指标 + 数据来源 + 口径说明。

## 硬规则

1. **数据可追溯**：每个数字来自读取结果；材料没有的数据一律不写，缺数据用"（材料未提供）"占位
2. **不编造**：不猜测数值、不补全缺失行
3. **口径明确**：合计/均值/占比都注明计算方式与范围
4. **先读后算**：未 inspect/read 前禁止输出任何数据结论
5. **产物写入工作区**：文件名体现主题（如 `销售数据统计.xlsx`）
6. **多轮修正**：用户要求调整（替换指标/增删列/改格式）时直接改对应部分并重新交付

## 交付

- 产物写入工作区后用文件交付能力呈现
- 汇报说明：读了哪些数据、算了几项指标、口径、遗留缺口
